# Best Friends Forever

An interactive React magazine about friendship, created for an English class project.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`.

## GitHub Pages

The project includes a GitHub Actions workflow that builds and deploys the site on pushes to `main`. In the repository, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. After the first successful workflow, the site is available at:

<https://shahzodbekT.github.io/best_friends_forever_magazine/>

The magazine includes six editorial sections, an interactive friendship quiz, an audience poll, an activity filter and randomizer, research links, an editable team checklist, and classroom presentation notes.
